# 🍎 Convite Digital Infantil — Romana

Projeto de um convite digital interativo desenvolvido para uma comemoração
infantil com tema Branca de Neve Baby.

## 🎯 Objetivo

Criar uma experiência digital simples, elegante e responsiva,
permitindo que os convidados visualizem todas as informações da
comemoração através de uma navegação por telas.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
- ChatGPT
- Google Gemini AI

## ✨ Funcionalidades

- Navegação entre telas
- Design responsivo
- Contagem regressiva
- Botão de localização integrado ao Google Maps
- Navegação de retorno à página inicial
- Interface otimizada para dispositivos móveis
- Elementos interativos em JavaScript

## 📱 Responsividade

O projeto foi desenvolvido com foco em dispositivos móveis,
mas também recebeu ajustes para visualização em notebooks e desktops.

## 🧠 Principais desafios

Durante o desenvolvimento, trabalhei principalmente com:

- adaptação de imagens verticais para diferentes tamanhos de tela;
- posicionamento de elementos sobre imagens;
- criação de áreas clicáveis;
- funcionamento da navegação entre as telas;
- implementação da contagem regressiva;
- integração com o Google Maps;
- testes em diferentes dispositivos.

## 📚 O que aprendi

Este projeto me permitiu colocar em prática conhecimentos de:

- estruturação de páginas HTML;
- estilização com CSS;
- responsividade;
- manipulação do DOM;
- eventos em JavaScript;
- organização de arquivos;
- Git e GitHub;
- publicação utilizando GitHub Pages.
